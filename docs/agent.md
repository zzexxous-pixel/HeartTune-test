# agent.md — 오늘심박(HeartTune) 인수인계

> 최종 갱신: 2026-10-27 (KST). 현재 구현·유효한 결정과 재발 방지 근거만 유지한다.
> 과거 세션 지시·폐기된 중간 UX·일회성 상태는 제거했다. 상세 변경은 Git 이력을 참조한다.

## 0. 작업 시작

1. `git status -sb`, `git log --oneline -10`으로 현재 작업본을 확인한다.
2. 문서는 `10-spec.md` → `20-architecture.md` → `30-algorithm-dsp.md` → `40-deployment-guide.md` 순으로 확인한다.
3. 변경 범위에 맞춰 `npm run lint`, `npm run test:i18n`, `npm run test:unit`, `npm run build`를 실행한다.
4. UI 변경은 실제 렌더링과 해당 회귀를 확인한다. 전체 E2E/실기기/운영 확인을 실행했는지 구분해 기록한다.
5. 배포·PR·인증 권한은 현재 세션 환경에서 확인한다. 과거 세션의 403 제한을 영구 규칙으로 적용하지 않는다.

## 1. 제품과 현행 동작

- 휴대폰 전용 Vanilla JS ES-module PWA. 이름은 오늘심박/HeartTune, 기본 후면 카메라·30초·자동 시작 OFF, 15/30/60초 선택.
- 카메라 프레임 중앙 ROI에서 R 우세 시 R, 그 외 G를 선택한다. 첫 3초 카메라 샘플을 버리고, 유효 약 5초 확보 후 경과 약 8초부터 2초 주기로 분석한다. 품질≥50·합의≥2·prior/hold 제외·신호 경고 없음일 때만 새 잠정 BPM을 표시한다.
- 100dvh 원스크린, 링 → 파형 → 메시지 고정 영역. 카메라 미리보기 54px. 상세·이력·설정·안내·법적 고지는 시트다.
- 측정 전 진입 미리보기는 토치 OFF, 측정 중 후면 토치를 지원하는 경우 켠다. 화면 조명·토치 미지원 경고·렌즈 목록 UI는 없다.
- 이력은 localStorage 최대 100건, 캘리브레이션 최근 30건. 파형 저장은 최근 최대 90샘플. 서버 전송 없음. 로컬 저장이 개인정보·유실 위험 0을 뜻하지는 않는다.
- 이력 행 선택은 같은 시트 안 자세히 보기. 전체 스와이프 후 3초 삭제 취소, 중간에 놓으면 닫힘. 전체 삭제는 확인 다이얼로그 후 이력·캘리브레이션 삭제.
- 뒤로가기는 열린 상세·시트를 순서대로 닫고, 메인에서는 브라우저 기본 동작. 종료 가드·더블백·종료 확인창 없음.
- 공유 PNG는 `detail-view.js` 단일 뷰모델을 사용한다. 동기 `toDataURL()` 인코딩으로 사용자 활성화를 유지한다. 파일 공유 조건 미충족 시 다운로드, 공유 시트 취소·실패 시 미저장. 저장 버튼은 항상 다운로드.
- 설치는 `beforeinstallprompt`를 수신한 경우 설정 버튼을 노출한다. 설치 배너·설치 완료 토스트·저장 진행 토스트·새 탭은 없다.
- 언어는 ko/en. `i18n.js` 인라인 사전, 브라우저 언어 감지·설정 저장·날짜 포맷을 담당한다. `setLang()`은 방어적으로 HTML lang도 변경한다.
- 개발/프리뷰 환경 표식 및 설치 이름은 `40-deployment-guide.md` 10절. 운영 이름·번역·공유 PNG는 유지한다.

## 2. 유지할 원칙

- 진단·건강 보증 금지, 결과·상세·공유에 참고용 고지. CV 0.14는 임상 검증값이 아닌 잠정 기준이다.
- 카메라 영상·측정 데이터의 서버 전송 및 외부 분석 금지. 공유는 사용자 동작으로만 수행한다.
- 18px 본문·48px 터치 영역은 목표 원칙이다. 현행 작은 글자·시트 헤더 버튼 등의 크기는 사용자 결정으로 유지한다. 목표 충족 완료로 표기하지 않는다.
- 일반 버튼 활성화는 click으로 단일화한다. 시트·이력 제스처의 Pointer/Touch 이중 경로와 스크롤 우선·방향 잠금은 유지한다.
- 상태는 색만으로 전달하지 않는다. 결과 신호는 독립 표시, 품질은 별도 색 체계. 키보드 포커스·아이콘 버튼의 접근 가능한 이름을 유지한다.
- 광고는 이력 하단만. 현재 실제 광고 SDK는 없고 법적 고지 자리다. 네트워크 도입 시 광고 식별·개인정보 문구를 함께 갱신한다(`50-ad-strategy.md`). 제휴 쇼핑은 보류, 광고 제거 유료 옵션 없음.
- 화면 번역은 i18n 키로 관리한다. 환경 식별자 dev/pre와 요청된 설치 이름은 언어 전환과 무관한 고정 표식이다.

- 개발 저장소 main → `ci.yml` → `verify.yml` 검증 후 개발 Pages 배포. PR은 `preview-pr.yml`로 `/preview/` 배포, 루트는 최신 main 유지.
- 운영은 `promote-to-production.yml` 수동 실행(`confirm=PROMOTE`)만. 검증 산출물을 `ACTIONS_DEPLOY_PAT`로 운영 저장소에 이관하고 스모크 확인한다.
- 새 런타임 파일은 SW `ASSETS`와 빌드 `RUNTIME_FILES` 양쪽 등록. 빌드는 파일 존재·HTML 직접 참조/상대경로·산출물 해시를 검사하지만 모든 JS import와 SW 캐시 목록의 교차 일치는 보장하지 않는다.
- `.js`/`.css` 해시 주입 대상과 `.webmanifest` 목록은 `RUNTIME_FILES`에서 파생한다. 스모크는 dist의 JS/CSS/모든 webmanifest를 열거한다. 자산 목록 사본을 다시 만들지 않는다.
- `CACHE_NAME`은 빌드가 자동 생성한다. 모든 자산은 상대경로, `dist/`는 커밋하지 않는다.
- 브랜치·PR은 현재 세션의 지시를 따른다. 과거 브랜치를 작업 대상으로 재사용하지 않는다. 병합·운영 이관은 승인 없이 실행하지 않는다.

## 4. 회귀 방지 근거

1. **하모닉 혼동:** FFT 단독 최대 피크는 2배 심박을 선택할 수 있다. FFT·자기상관·IBI 합의와 시간영역 중재를 보존한다. DSP 회귀 13~15번 참조.
2. **카메라 안정화:** 첫 3초 자동노출 요동이 가짜 피크·IBI 이상치를 만들었다. 샘플 제외와 MAD 정제 근거·실측 재현은 `30-algorithm-dsp.md` 2-2절. 불규칙 리듬 보존 테스트도 유지한다.
3. **터치 회귀:** 빠른 스와이프의 세로 드리프트가 브라우저 스크롤로 인계되어 삭제 취소 첫 탭이 억제됐다. 가로 방향 확정 후 Touch preventDefault와 공유 클릭 억제 시각을 유지한다. 키보드 삭제 접근도 유지한다.
4. **해시 거짓 실패:** detail-view.js의 주입 누락으로 운영은 배포됐는데 스모크가 실패했다. 자동 목록·dist 자기검사·사전 점검과 빌드 스크립트 자체 해시 입력을 유지한다. 상세는 `40-deployment-guide.md` 8-2절.
5. **스모크 실패 구분:** 배포 지연이면 원격 재확인 가능, 산출물 자체 해시 누락이면 동일 artifact 재실행은 무의미하다. 코드 수정 후 새 이관이 필요하다.
6. **공유 활성화:** 비동기 toBlob 콜백 후 모바일 사용자 활성화가 만료될 수 있어 동기 인코딩을 사용한다.
7. **CSS 우선순위:** 누적 override를 일괄 삭제하면 최종 레이아웃이 달라진다. 활성 스타일 통합은 보류다.
8. **테스트 환경:** ko-KR 로케일, fake media, 콘솔 오버레이의 CTA 가림, 가짜 시계의 CSS transition 영향에 주의한다. 브라우저 설치 제한은 세션별로 판단한다.

## 7. 문서 운영

현재 규칙과 과거 경위를 섞지 않는다. 폐기 정책은 현행 명세에서 제거하고 재발 방지에 필요한 원인만 요약한다. 검증은 실제 실행 범위·날짜를 구분해 기록하고, 확인하지 않은 상태를 완료로 쓰지 않는다. 의료 표현·판정 기준·UX 변경은 사용자 결정 없이 문서 정리라는 이유로 구현하지 않는다.

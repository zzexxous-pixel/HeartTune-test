## 4. 컨셉 결정 사항

## 4-1. 측정 방식 — ✅ 확정: 손가락 PPG
| 방식 | 결정 |
|---|---|
| **A. 손가락 PPG** | ✅ **채택**. 검지를 후면 카메라+플래시에 대고 혈류 색 변화 측정 |
| B. 얼굴 rPPG | ⏸ **보류**. "재밌겠다"는 의견 → 향후 별도 기능으로 검토 |

**구현 파이프라인 (안)**
1. `getUserMedia({ video: { facingMode: 'environment' } })` + `torch: true` (플래시, 지원 기기만)
2. `requestVideoFrameCallback`으로 프레임 수신 → `<canvas>`에 축소 렌더링 (예: 64×64)
3. 프레임당 **평균 녹색채널(G) 값** 추출 → 시계열 배열
   *(PPG는 녹색광 흡수 변화가 가장 큼. 적색채널 대비 SNR 우수)*
4. 대역통과 필터 **0.7~4.0 Hz** (= 42~240 BPM) → 저주파 호흡·고주파 노이즈 제거
5. 주파수 분석: **FFT** (슬라이딩 윈도) + **자기상관(autocorrelation)** 병행 → 피크 BPM
6. 피크 검출로 **박동 간격(IBI)** 추출 → 변동성(RMSSD / CV) 계산

## 4-1b. 측정 진행 로직 — 현행 구현

- 측정 시작 시 신호를 수집하고 약 **5초부터 첫 BPM**을 표시한다.
- 측정 중에는 약 2초 간격으로 적응형 추적과 BPM 표시를 갱신한다.
- 설정한 15/30/60초 측정 종료 시 최종 결과와 전체 구간의 리듬 참고 신호를 표시한다.
- 링 진행률과 파형은 측정 중 계속 표시한다. 파형은 측정 전 기준선, 측정 후 마지막 측정 파형을 유지한다.
- 15초 측정에는 짧은 측정 결과임을 알리는 참고 문구를 표시한다.


## 4-2. 결과 참고 신호 — UI 문구 확정
| 참고 항목 | 표시 기준(현행 DSP 기준 유지) | 화면 표시 |
|---|---|---|
| 서맥 | 심박수 < 60 BPM | "서맥 참고 신호" |
| 일반 범위 | 심박수 60~100 BPM | "정상 범위예요" |
| 빈맥 | 심박수 > 100 BPM | "빈맥 참고 신호" |
| 부정맥 참고 신호 | BPM과 무관하게 현행 IBI 변동 기준 초과 | "부정맥 참고 신호" |

세 항목(부정맥·서맥·빈맥)은 상세 시트에서 **각각 독립적으로** 표시한다. 기존 DSP는 irregular를 대표 `status`로 우선 반환하지만, 화면 플래그는 같은 60/100 BPM 경계를 재사용해 다른 조건도 함께 표시한다. **임계값과 신호처리 알고리즘은 이 UI 작업에서 바꾸지 않는다.** 상세 표시등은 빨강(신호 있음)/초록(신호 없음)이며, 상태 문구를 함께 제공한다. 측정 신호 품질은 별도 파랑/황색/회색 상태 체계로 구분한다.

> ⚠️ 카메라 PPG 결과는 진단이 아니다. 부정맥 여부를 단정하거나 건강을 보증하지 않고, 결과와 법적 고지에 참고용임을 명시한다.

> ⚠️ **측정 길이별 판정 범위**
> | 측정 시간 | 심박수(BPM) | 리듬(부정맥) 판정 |
> |---|---|---|
> | 15초 | ✅ 가능 (박동 15~25개) | ⚠️ 참고 수준 — 신뢰도 낮음 |
> | **30초 (기본)** | ✅ | ✅ **가능 (박동 30~50개)** |
> | 60초 | ✅ | ✅ 가장 안정적 |
>
> → **기본값을 30초로 정한 이유**: 리듬 판정에 필요한 최소 박동 수를 확보하면서도 사용자가 견딜 수 있는 길이. 15초 옵션은 "빠른 확인"용으로 두되, 리듬 판정 시 **"짧은 측정이라 참고만 하세요"** 안내 병기

## 4-5. 중장년 타깃 → UI 설계 원칙
- **기본 글자 18px 이상**, 핵심 수치는 **64px 이상**
- **탭 영역 최소 48×48dp** (손떨림·노안 고려)
- 화면 요소 최소화: 한 화면에 **"측정 시작" 버튼 하나**가 주인공
- 색상만으로 상태 전달 금지 → **색 + 아이콘 + 텍스트** 동시 사용 (색각 이상 대비)
- 측정 실패 시 원인을 **구체적으로** 안내 ("손가락을 조금 더 꾹 눌러주세요", "너무 밝은 곳이에요")
- 가족 공유: 결과를 **큰 글씨 이미지**로 저장해 카카오톡 등으로 전송 가능하게

## 4-5b. 한 화면(원스크린) UI — ✅ 확정 (2026-10-20)

휴대폰 첫 화면은 100dvh 고정 레이아웃이며, 상태가 바뀌어도 **링 → 파형 → 메시지**의 영역 순서·크기를 유지한다.

```
[헤더 52px]  ❤️ HeartTune                       [≡] [언어] [⚙️]
[스테이지: 고정 3영역]
  링: 카메라 미리보기 + BPM + 타이머
  파형: 대기(수평 기준선) → 측정(실시간) → 결과(마지막 파형)
  메시지: 대기/측정 안내 또는 결과·상세 버튼·참고용 고지
[하단 CTA]  [이미지 저장] [   측정 시작   ]
```

| 결정 | 내용 |
|---|---|
| 레이아웃 | 헤더·3영역 스테이지·하단 CTA, `body{overflow:hidden}` + `100dvh` → 스크롤 없음 |
| 영역 고정 | 대기·측정·결과에서 링·파형·메시지의 순서와 영역 크기 유지 |
| 파형 | 상시 표시. 대기 시 수평 기준선, 측정 중 실시간 파형, 결과 후 마지막 파형. 설명 문구는 추가하지 않음 |
| 옵션 | 측정 시간·전/후면 카메라·언어를 설정 시트에서 선택. 화면 조명 및 파형 토글은 없음 |
| 기본값 | **후면 기본 카메라**, 30초, **자동 시작 OFF**. 전면 선택은 제공하되 후면 렌즈 목록은 노출하지 않음 |
| 카메라 | 페이지 진입 즉시 미리보기(토치 OFF), 후면 카메라의 측정 중 토치 동작 유지. 토치 미지원 경고 UI는 없음 |
| 미리보기 크기 | 54px 원형 유지 |
| 메시지 영역 | 결과 제목과 자세히 보기 버튼은 상단 고정, 설명은 하단 영역 세로 가운데 정렬. 측정/결과 문구를 수용하는 고정 높이 |
| 상세 결과 | 측정일시·측정시간·맥박·파형 + 부정맥·서맥·빈맥(빨강/초록 표시등) + 측정 신호 품질 + 읽기 쉬운 참고 고지. CV·박동 수·채널·스트레스 제외. 큰 글씨·작은 화면 세로 스크롤 지원 |
| 최근 이력 | 그래프 점은 정상 초록/비정상 빨강, 점 크기 확대. 신호등 없이 텍스트로 `정상`, `부정맥 의심`, 복수 항목은 `부정맥, 빈맥 의심` 형식. 서맥/빈맥이면 맥박 숫자도 빨강 |
| 공유 이미지 | 제목 `❤️ 오늘심박 (HeartTune)` / `❤️ HeartTune`, 중앙 정렬, "카메라 맥박 파형" 표기, 큰 하단 글자, 빈 정상신호 항목 제거, 줄바꿈·가변 높이 |
| 법적 고지 | 결과·상세 화면에 참고용 표기, 메뉴의 법적 고지 시트에 전문 |
| 디버그 창 | 타이틀 5연타로 열고 상단 경계 드래그·키보드로 높이 조절 유지 |
| 접근성 | BPM 64px 이상, 버튼 48×48px 이상, 상태 색상에는 텍스트 설명 병행 |

## 4-6. 법적 표기 (필수)
- "본 앱은 의료기기가 아니며, 측정 결과는 참고용 정보입니다. 의학적 판단이나 진료를 대체할 수 없습니다."
- 카메라 권한 요청 사유 고지
- 영상 데이터 서버 전송 없음(브라우저 내 처리) 명시 → 개인정보 신뢰도 확보

## 4-7. 측정 이력 — ✅ 브라우저 저장
- 저장소: **`localStorage`** (서버 없음 → 개인정보 리스크 0, 오프라인 동작)
- 저장 항목(안): `{ 측정시각, BPM, 판정결과, 리듬변동성, 측정길이, 신호품질 }`
- 표시: 최근 N건을 **그래프(추세선) + 목록**으로. 중장년 타깃이므로 "지난주보다 느려졌어요" 같은 **비교 문구**가 숫자보다 효과적
- ⚠️ **한계 고지 필요**: localStorage는 **브라우저·기기별** 저장이라 PC에서 측정한 값이 휴대폰에 안 보임. "이 기기에만 저장됩니다" 문구 명시
- ⚠️ localStorage 용량 한도(약 5MB) → 보관 개수 상한을 정하고 오래된 것부터 자동 삭제 (예: 최근 200건)

## 4-8. 결과 공유 — ✅ 이미지 저장
- **Web Share API** 우선 (`navigator.share({ files })`) → 모바일에서 카카오톡 등으로 바로 공유
- 미지원 브라우저(PC 등) 폴백: `<canvas>` → `toBlob()` → **다운로드 링크**
- 이미지 구성(안): 로고(오늘심박/HeartTune) + 큰 BPM 숫자 + 판정 문구 + 측정 시각 + 법적 고지 한 줄
- ⚠️ **가족 공유가 핵심 유스케이스**: 부모님이 혼자 보셔도 자녀가 바로 알아볼 수 있게 **큰 글씨·높은 대비**로 생성

## 4-9. PWA — ✅ 지원
- `manifest.webmanifest` + Service Worker 등록
- 아이콘: 192px / 512px / maskable, iOS용 `apple-touch-icon` 별도
- **오프라인 동작**: 정적 자원 캐싱 → 인터넷 없이도 측정 가능 (카메라는 로컬 API)
- 설치 유도: Android `beforeinstallprompt`, iOS는 **"홈 화면에 추가" 안내 배너** 필요 (자동 설치 프롬프트 미지원)
- ⚠️ iOS PWA는 localStorage가 **장기간 미사용 시 정리될 수 있음** → 이력 유실 가능성 고지

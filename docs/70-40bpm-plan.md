# 70 · 40 BPM 지원 확대 작업 계획

> 2026-10-27. 사용자 요청에 따른 **계획**이며, 아래 DSP 변경은 아직 실행하지 않았다.
> 현재 tracking 진입 조건은 45~195 BPM이다. 숫자 45 하나만 40으로 바꾸는 작업이 아니다.

## 1. 목표·변경하지 않을 것

- 지원 목표 하한: **40 BPM**. 중증 환자 전용 기능이 아니라 일상 사용자의 낮은 심박수도 잘못 배제하지 않기 위한 범위다.
- tracking 상한 195, 서맥 참고 신호 경계 60, 빈맥 경계 100, CV 0.14, IBI MAD 정제는 유지한다.
- 40 BPM 미만을 정확히 측정한다는 주장은 하지 않는다. 값만으로 정상·질환을 단정하지 않는다.
- 현재 승인된 실시간 정책(처음 3초 제외, 유효 약 5초 확보 후 약 8초부터 분석, 이후 2초 갱신)과 품질/합의 게이트는 유지한다. 40 BPM은 5초에 약 3.3박동뿐이므로 첫 분석에서 반드시 표시한다고 보장하지 않는다.
- 최종 15/30/60초 결과 정책 변경은 별도 승인 없이 추가하지 않는다. 특히 15초 결과의 한계를 명시하고 30초 기본값을 유지한다.

## 2. 현재 코드에서 함께 확인할 부분

| 부분 | 현재 | 검토 방향 |
|---|---|---|
| 초기 광대역 highpass | 0.7Hz(약 42 BPM) | 40 BPM(약 0.667Hz)의 기본파를 과도하게 감쇠하지 않는 하한을 검증. 우선 0.6Hz 후보와 기존값 비교 |
| FFT 탐색 | 0.7Hz 기준 bin | 40 BPM 기본파를 일관되게 포함하도록 탐색 경계 변경; bin 양자화·보간까지 확인 |
| 자기상관 최대 lag | 42 BPM 기준 | 40 BPM 주기의 lag를 포함하고 경계에서 국소 피크가 누락되지 않게 인접 lag 여유 확인 |
| 초기 시간영역 합의 | autocorr·median >42 | 40 BPM 경계 포함 및 추정 오차 여유 검토. 유효성 검사 30~220과 지원 범위는 분리 |
| tracking 진입 | 45~195 | 40~195로 변경하되 기본파/2배 하모닉 선택 회귀를 먼저 고정 |
| tracking·prior 대역 하한 | max(0.65, …) | 40 BPM 근처에서 대역 감쇠·필터 천이·기저값 편향을 함께 측정 |
| 기저값/저장 baseline | 이전 측정 필터 평균 | 예전 0.7Hz baseline으로 신규 40 BPM이 계속 배제되지 않는지 확인. 기존 데이터 무조건 삭제·저장 키 변경 금지 |
| 실시간 표시 | 품질≥50·합의≥2·prior/hold 배제 | 저품질을 통과시키려고 기준을 느슨하게 하지 않는다. 수집이 더 필요하면 숫자를 기다린다 |

숫자를 각각 임시 수정하지 않고, 지원 범위·탐색 경계의 근거를 명확하게 관리한다. 범위 상수를 도입한다면 모든 임계값을 무조건 동일한 값으로 묶지 않는다(필터 전이대역과 표시 범위는 역할이 다름).

## 3. 작업 순서

1. **기준 성능 고정:** 현재 코드의 기존 테스트 및 아래 저심박 행렬을 실행해 BPM·오차·박동 수·quality·추정 source/agreement·filter mode를 기록한다. 기존 코드에서 재현된 40 BPM 2배 추정도 고정한다.
2. **탐색 경계 정합:** FFT·자기상관·초기 합의가 40 BPM을 실제로 후보에 포함하도록 테스트 우선 변경한다.
3. **필터·tracking 조정:** 하한 후보를 비교하고 40 BPM 기본파 보존과 느린 움직임 유입 사이의 균형을 선택한다. tracking 숫자 변경은 이 단계에서 함께 수행한다.
4. **기저값·연속 갱신 검증:** 신규 사용자 prior72, 기존 baseline, 정상/높은 prior에서 40 BPM으로 진입, 40→60→100 변화, 잡음 후 Hold/회복을 검증한다.
5. **회귀·비용 비교:** 기존 45~140 중첩파 회귀와 55/72/90/130, 부정맥 보존·아티팩트 정제·신호 게이트가 나빠지지 않았는지 비교한다. 처리 시간도 변경 전후 같은 환경에서 비교한다.
6. **실측 확인 후 명세 갱신:** 가능하면 기준 기기와 동시 측정한 낮은 심박의 실제 PPG로 확인한다. 합성 통과만으로 임상 정확도나 40 BPM 지원 검증 완료라고 쓰지 않는다. 검증이 부족하면 릴리스 주장을 보류한다.

## 4. 테스트 행렬과 완료 기준

- 심박수: **38/39(하한 밖 경계 관찰), 40/41/42/44/45/50/55/60/72/90/100/130**.
- 유효 신호 길이: **2/5/7/10/12/27/57초**, 15/30/60초 카메라의 첫 3초 제외와 샘플링 지연도 별도 검증.
- 여러 결정적 seed, 위상·샘플링 지터, 약한/강한 중첩파, DC 변화, 호흡성 저주파, 노이즈·단발 움직임·접촉 끊김, 불규칙 리듬 포함.
- 무잡음/약잡음의 40~50 BPM·충분한 입력에서 목표 오차 **±3 BPM**을 우선 기준으로 둔다. 강잡음 허용 오차는 기존 **±6 BPM** 회귀와 비교하되, 기준을 통과하지 못하면 잘못된 숫자 표시보다 표시 보류가 우선이다.
- 40이 80으로 고정되는 오류, 기준 밖의 느린 움직임을 정상 tracking으로 잠그는 오류를 방지한다.
- 기존 단위·E2E 회귀 전부 통과. 규칙/불규칙 리듬 판정 기준을 하한 지원을 위해 임의로 완화하지 않는다.
- 하한 범위 확대는 계산량의 큰 증가가 예상되는 변경은 아니지만, 실제 분석 실행 시간과 갱신 간격 준수를 측정한다.
- 모든 조건에서 8초 첫 표시를 보장하는 것은 완료 기준이 아니다. 낮은 심박은 추가 수집 후 표시할 수 있다.
